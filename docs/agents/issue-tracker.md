# Issue Tracker: GitHub Issues

Approved specifications and multi-step work for Chirawn live in GitHub Issues for this repository.

## Use It For

- approved substantial features;
- specifications that need traceability;
- ticketed work with real dependencies;
- verified bugs and technical debt that should survive a chat/session.

Do not create an issue for a tiny self-contained UI adjustment unless Art asks for tracking.

## Conventions

- Use concise, user-outcome-focused titles.
- State acceptance criteria and blockers for multi-step work.
- Link the originating decision or specification when applicable.
- Record the final verification result before closing an issue.
- Pull requests are not a request surface for the product backlog.

## Agent Operations

When a workflow says to publish or fetch a ticket, use the connected GitHub integration or the GitHub CLI from a valid local checkout. Confirm the exact repository and target issue before a write action.
